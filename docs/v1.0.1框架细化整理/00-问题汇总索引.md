## 三、现存问题详细说明

### 3.1 ❌ #31 角色模板两个 constants 文件 key 不同 — 严重度：高

**现状**：两个文件定义了功能重叠的角色模板，key 命名不一致：

| 文件 | 导出名 | 苏格拉底 key | 接口 | 使用方 |
|------|--------|-------------|------|--------|
| `constants/personaTemplates.ts` | `PERSONA_TEMPLATES` | `'socrates'` | `PersonaTemplate`（5字段） | `CreatePersonaModal` |
| `constants/characterPresets.ts` | `SAGE_TEMPLATES` | `'socratic'` | `SageTemplate`（7字段） | `SageCreateFlow` |

**风险**：同一概念（苏格拉底型教师）在两条创建路径中产生不同的 `template_name`，后端无法统一关联。`personaTemplates.ts` 有 5 个模板（含 `custom`），`characterPresets.ts` 有 6 个模板（含 `yoda` 和 `free`，无 `custom`）。两套 `TraitSlider` 接口字段也不同（`name/min/max/default` vs `label/leftLabel/rightLabel/defaultValue`）。

**解决方案**：
1. 确定唯一权威源：保留 `characterPresets.ts`（字段更丰富，已有 `nameEn`/`color`/`greeting`）
2. 将 `CreatePersonaModal` 迁移为引用 `SAGE_TEMPLATES`，删除 `personaTemplates.ts`
3. 统一 `TraitSlider` 接口，保留 `characterPresets.ts` 版本（带 `leftLabel`/`rightLabel` 更利于 UI）
4. 如需 `custom` 模板，在 `SAGE_TEMPLATES` 末尾补充

### 3.2 ❌ #22 背景图片硬编码 — 严重度：中

**现状**：8 个 View 各自硬编码背景图引用，没有统一管理：
- `Login.vue` → `loginBg`
- `Home.vue` / `Worlds.vue` → `homeBg`
- `Character.vue` / `WorldDetail.vue` / `CoursePage.vue` / `Archive.vue` / `Settings.vue` → 各自定义 `BG_URL`

**解决方案**：
1. 在 `constants/ui.ts` 中新增 `PAGE_BACKGROUNDS` 映射表，集中管理所有页面背景
2. 各 View 从 `PAGE_BACKGROUNDS` 读取，不再各自 import 图片
3. 后续可扩展为后端配置驱动（World 级别自定义背景）

### 3.3 ❌ #23 MOCK_CHARACTERS 重复定义 — 严重度：中

**现状**：`Character.vue:163` 和 `WorldDetail.vue:342` 各自定义了独立的 `MOCK_CHARACTERS` 数组。内容相似（相同角色名），但 id、color 格式不同：
- `Character.vue`: `id: 1-4, 101-102`，`color: COLORS[i]`
- `WorldDetail.vue`: `id: 10-13, 110-111`，`color: 'rgba(...)'`

**解决方案**：
1. 在 `constants/characterPresets.ts` 中新增 `FALLBACK_CHARACTERS` 统一定义
2. 两个 View 共同引用，删除各自的局部定义
3. 长期方向：后端 seed 数据保证有默认角色，前端不再需要 mock fallback

### 3.4 ❌ #26 重复组件文件名 — 严重度：中

**现状**：`components/` 根目录和 `components/galgame/` 子目录存在 3 对同名组件：

| 根目录（活跃） | galgame/（死代码） |
|----------------|-------------------|
| `DialogBox.vue` (245行) | `DialogBox.vue` (230行) |
| `BacklogPanel.vue` (84行) | `BacklogPanel.vue` (152行) |
| `HudBar.vue` (110行) | `HudBar.vue` (104行) |

经验证：**`galgame/` 子目录的 3 个同名组件无任何引用方**。`Learning.vue` 引用的全部是根目录版本。`galgame/` 目录下仅 `ToolConfirmDialog.vue`、`CharacterDisplay.vue`、`CheckpointPanel.vue` 可能仍有用途（需进一步确认）。

**解决方案**：
1. 确认 `galgame/` 下 `ToolConfirmDialog.vue`、`CharacterDisplay.vue`、`CheckpointPanel.vue` 是否有引用
2. 删除 `galgame/` 下无引用的同名文件（`DialogBox.vue`、`BacklogPanel.vue`、`HudBar.vue`）
3. 如果 `galgame/` 目录整体无引用，直接删除整个子目录
